# Universal AI Hub V3 / 1.1.0

## Included
- Automatic model discovery for supported APIs.
- Model dropdown after discovery.
- Manual model entry fallback.
- Chat history refresh fixes.
- Conversation search, rename, delete and export.
- Streaming, stop generation, regeneration and message editing.
- Secure API-key storage and secret masking.
- Provider configuration export without API keys.
- GitHub Actions: Java 17, dependency install, analyze, tests, release APK artifact.

## Build
Push to GitHub and download the successful APK from Actions -> Artifacts.
